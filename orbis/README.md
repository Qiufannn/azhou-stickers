# Orbis 表情包兼容源

这里不修改 Orbis，也不 fork Orbis。

`orbis-sticker-source.json` 是从仓库现有 `stickers.json` 自动整理出的兼容源清单，保留：
- 原始三位编号
- 原名称
- 原标签
- 原图片 URL
- 额外把“名称”放进 tags 第一项，方便 Orbis 这种只有标签检索的表情库保留名称搜索能力

当前上游 Orbis 的图片表情管理只提供“单张系统选图 → 填标签 → 保存”，并没有公开的批量 JSON/ZIP 导入入口，所以本文件**不是伪装成已经可直接导入的格式**。

用途：
1. 如果上游以后增加批量导入，可直接根据这份清单转换。
2. 如果以后只做一个很薄的临时导入补丁，不需要重新整理 101 张表情。
3. 原 `stickers.json` 继续作为现有 MCP/网页表情库的主数据，不被替换。

生成时共有 101 张表情。
